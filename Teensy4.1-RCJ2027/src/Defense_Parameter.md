# `act_defense_smach3.cpp` 参数中文含义与用途说明

本文档整理了 `Teensy4.1-RCJ2027/src/act_defense_smach3.cpp` 中所有宏定义（`#define`）参数的**中文含义与具体用途**。

---

## 1. 基础硬件与巡线停靠（DEFEND：禁区线控制）

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `MOTOR_REVERSE` | `0` | **电机方向反转开关**：`1` 为进攻车体（接线相反），`0` 为防守车体。 |
| `SPEED` | `30` | **基础前后速度**：在禁区线上进行前后调整的基础速度（%）。 |
| `BACK_SPEED` | `15` | **避让边线速度**：当侧边圆环传感器压线时，向远离白线方向退让的最小速度。 |
| `FINE_SPEED` | `15` | **微调速度**：围绕 `FRONT_OUT` 停靠点做前后小幅位置修正时的速度。 |
| `MIN_SPEED` | `15.0f` | **最小有效速度**：实际场地中低于此值的非零输出无法驱动机器人移动，所有非零动作都会被抬升至此下限（保留原方向）。 |
| `DEF_SLOW_GOAL_DEG` | `35.0f` | **禁区边缘减速起始角**：摄像头测得后方球门偏离 `270°` 超过此角度时，继续远离球门的横向移动开始减速。 |
| `DEF_SIDE_GOAL_DEG` | `60.0f` | **禁区边缘截止角**：球门偏离 `270°` 达到此角度（禁区线末端）时，远离球门的横向速度降至 `0`。 |
| `LOCK_HEAD_DEG` | `10.0f` | **角落锁定朝向容差**：只有机器人朝向在 `90° ± 10°` 范围内时，才会触发“前传感器 + 侧臂同时压线”的角落锁定。 |
| `LOCK_PUSH_DEG` | `5.0f` | **被推入解锁阈值**：处于角落锁定状态时，若摄像头检测到机器人朝球门方向被推退了此角度（被对手挤入禁区），立即解除锁定以便脱困。 |
| `BACK_LINE_SPLIT_CM` | `3.0f` | **后传感器压线判别阈值**：仅后传感器压线而前传感器未压线时，若摄像头判定机器人中心超出禁区前线此距离，说明已冲出禁区（切入 `RETURN`）；否则说明压到了底线/侧线（向前恢复）。 |
| `RECOVER_SPEED` | `30.0f` | **被推入恢复起始速度**：前端丢失禁区线（被对手推入禁区内）时，向前找线的起始速度。 |
| `RECOVER_MAX` | `60.0f` | **被推入恢复最大速度**：向前找线时的速度上限。 |
| `RECOVER_RAMP` | `0.01f` | **恢复加速度斜率**：每毫秒增加的速度百分比（`0.01%/ms`，即 3 秒内从 30% 线性升至 60%）。 |

## 2. 横向防守移动（DEFEND：横向对齐）

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `DEF_SIDE_KP` | `1.0f` | **有球横向比例增益**：看到球时，机器人偏离“球—球门中心连线”每度对应的横向移动速度。 |
| `DEF_GOAL_KP` | `1.0f` | **无球回中比例增益**：丢球时，后方球门偏离 `270°`（正后方）每度对应的横向回中速度。 |
| `DEF_CENTER_DEAD` | `5.0f` | **横向死区（度）**：角度误差在此范围内时不进行横向移动，防止原地抖动。 |
| `DEF_SIDE_MAX` | `40.0f` | **最大横向速度**：`DEFEND` 状态下横向平移的速度上限。 |

## 3. 出击判定（DEFEND -> LEAVE 切换条件）

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `LEAVE_FRONT_DEG` | `5.0f` | **正前方窗口**：球在 `90° ± 5°`（即 `85°–95°`）内视为正对机器人前方。 |
| `LEAVE_HOLD_MS` | `3000` | **正前方持续时间（毫秒）**：球保持在正前方窗口内累计达 3 秒，触发 `LEAVE` 出击抢球。 |
| `LEAVE_BREAK_MS` | `200` | **抗噪容错时间（毫秒）**：球短暂跳出窗口小于 200ms 时视为传感器噪声，计时器不重置。 |
| `DEF_CORNER_GOAL_DEG` | `25.0f` | **禁区角落判定角**：我方球门偏离 `270°` 超过此角度，判定机器人位于禁区左右角落。 |
| `DEF_CORNER_R_MIN` / `MAX` | `40.0f` / `80.0f` | **右角落中立点球角区间**：机器人在右角落且球处于 `40°–80°`（对应规则 2.5 中立点位置）。 |
| `DEF_CORNER_L_MIN` / `MAX` | `100.0f` / `140.0f` | **左角落中立点球角区间**：机器人在左角落且球处于 `100°–140°`。 |
| `DEF_CORNER_HOLD_MS` | `4000` | **角落出击持续时间（毫秒）**：球在中立点区间停留满 4 秒，触发 `LEAVE` 出击。 |

## 4. 出击抢球（LEAVE 状态）

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `LEAVE_RUSH_SPEED` | `70.0f` | **直线冲球速度**：当球在 `85°–95°` 正前方时，直线全速冲向球的速度。 |
| `ORBIT_SPEED` | `25.0f` | **禁区外绕球速度**：离开禁区后，缓慢绕球调整角度直到将球对准 `90°` 的速度。 |
| `LEAVE_FAR_SPEED` | `60.0f` | **远球追击上限**：红外接近度（closeness）为 0（球较远）时的最大追球速度。 |
| `LEAVE_NEAR_SPEED` | `30.0f` | **近球追击上限**：红外接近度为 1（球很近）时的速度上限，防止高速撞飞或碾过球。 |
| `LEAVE_MAX_MS` | `4000` | **最长出击时间（毫秒）**：离开禁区抢球的最长持续时间（4 秒），超时强制返回。 |
| `LEAVE_MAX_DIST_CM` | `90.0f` | **最远出击距离（cm）**：距离我方球门超过 90cm 时放弃追球并返回。 |
| `BALL_LOST_MS` | `200` | **丢球返回阈值（毫秒）**：丢失球信号超过 200ms 立即结束 `LEAVE` 返回。 |
| `BEHIND_DEG` | `60.0f` | **球在身后判定角**：球进入 `270° ± 60°` 范围（说明球已越过机器人向我方球门滚去），立即返回防守。 |
| `LINE_SIDE_GOAL_DEG` | `45.0f` | **出击边线处理开启角**：球门偏离 `270°` 超过 45° 时才启用白线避让，避免误判禁区线。 |
| `PENALTY_ZONE_CM` | `60.0f` | **禁区白线屏蔽半径（cm）**：距离我方球门小于 60cm 时，忽略所有白线（此时遇到的白线必为禁区线而非场地边线）。 |

## 5. 返回禁区（RETURN 状态）与视觉几何标定

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `RETURN_SPEED` | `40.0f` | **返回最高速度**：回防时的最大移动速度（实测 50% 过快，故限制为 40%）。 |
| `RETURN_KP` | `0.7f` | **返回距离比例系数（P）**：每厘米剩余距离对应的速度增量（如距目标 57cm 时输出 40%）。 |
| `RETURN_KD` | `0.2f` | **返回速度阻尼系数（D）**：根据接近速度进行刹车阻尼（无 I 项，防止冲过停靠点）。 |
| `STOP_CM` | `8.0f` | **停靠点偏移（cm）**：目标让机器人中心停在禁区线内侧 `8.0cm` 处（即 `FRONT_OUT` 传感器正好压线）。 |
| `RETURN_SIDE_DEG` | `30.0f` | **球门侧方优先前移角**：当球门在 `0°` 或 `180° ± 30°`（机器人在球门两侧）时，先向前移动绕开禁区侧边，再切向球门。 |
| `RETURN_SIDE_HYST` | `10.0f` | **侧方退出迟滞角**：球门角度需偏离 `0°/180°` 超过 `30° + 10° = 40°` 才结束“先向前”阶段，防止临界震荡。 |
| `DODGE_DEG` | `30.0f` | **挡路球判定角**：球位于回防路径（球门方向）`± 30°` 内时，判定球挡在路上。 |
| `DODGE_OFFSET_DEG` | `60.0f` | **绕球偏转角**：检测到球挡路时，将回防航向朝场内（`90°` 方向）偏转 `60°` 绕开球，避免把球踢进自家球门。 |
| `DEFEND_MAX_CM` | `45.0f` | **防守最大脱线距离（cm）**：在 `DEFEND` 状态下若距球门超过 45cm，说明已被挤出禁区，强制切入 `RETURN`。 |
| `RETURN_TURN_DEG` | `20.0f` | **回正转向阈值**：`DEFEND` 或 `RETURN` 时，若车头偏离 `90°` 超过 20°，先原地转向回正再移动。 |
| `GOAL_K_DEG1` / `GOAL_K1` | `44.0f` / `0.81f` | **斜视角距离修正点 1**：摄像头斜看球门时测距偏长，偏离 `270°` 达 `44°` 时乘以修正系数 `0.81`。 |
| `GOAL_K_DEG2` / `GOAL_K2` | `66.0f` / `0.61f` | **斜视角距离修正点 2**：偏离 `270°` 达 `66°` 及以上时，测距乘以 `0.61`（中间角度线性插值）。 |
| `PA_FRONT_CM` / `PA_HALF_CM` / `PA_R_CM` | `30.0` / `39.0` / `15.0` | **禁区几何尺寸（cm）**：以摄像头球门坐标点（位于球门线内约 5cm）为原点的禁区前线距离、半宽及圆角半径。 |
| `DEPTH_FLOOR_CM` | `9.5f` | **摄像头深度底线（cm）**：当无前传感器压线时，若摄像头判定中心在禁区线后方超过 `9.5cm`（快要完全进入禁区），强制前移。 |
| `FIELD_HALF_LEN_CM` / `FIELD_HALF_W_CM` | `114.5` / `78.0` | **场地半长与半宽（cm）**：用于通过双球门角度 + 陀螺仪推算机器人 X 坐标，限制其靠近场地边线。 |
| `SIDE_STOP_CM` / `SIDE_LAMBDA_CM` | `14.0` / `20.0` | **场地边线软限位**：距边线 `14cm` 时向边线方向的速度降为 0，在 `20cm` 特征长度内呈指数衰减减速。 |

## 6. 超声波第二层安全保护（Ultrasonic R03）

| 参数名 | 默认值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `US_USE_FRONT` / `RIGHT` / `BACK` / `LEFT` | `1` / `1` / `1` / `1` | **四向超声波独立启用开关**：`1` 为启用，`0` 为禁用（若某探头硬件损坏可单独设为 `0`，系统会将其按失效处理）。 |
| `US_STALE_MS` | `200` | **数据包超时阈值（毫秒）**：超过 200ms 未收到传感器板（AB 包）数据，判定所有超声波失效。 |
| `US_FAIL_K` | `0.7f` | **传感器失效降速系数**：当某方向超声波关闭、读数为 0 或超时失效时，向该方向移动的速度乘以 `0.7`（仅靠摄像头保护，保守减速）。 |
| `US_WALL_STOP_CM` | `15.0f` | **侧墙停止距离（cm）**：左/右超声波距场边挡板小于 15cm 时，向该侧墙方向的速度限制为 0。 |
| `US_WALL_KP` | `1.5f` | **侧墙减速增益**：超出 `15cm` 停止线后，每厘米允许的向墙速度百分比（如 35cm 时允许 30% 速度）。 |
| `US_BACK_GOAL_CM` | `12.0f` | **球门前标准后距（cm）**：机器人正对球门站在禁区线上时，后超声波测得球门背板的基准距离。 |
| `US_BACK_WALL_CM` | `18.0f` | **球门旁标准后距（cm）**：机器人位于禁区线两侧末端时，后超声波测得场地后墙的基准距离。 |
| `US_BACK_MARGIN_CM` | `2.0f` | **后距安全余量（cm）**：后退下限 = 基准距离 - 2cm；低于此值说明被挤入禁区过深，立即向前推回。 |
| `US_BACK_KP` | `1.5f` | **后退减速增益**：`RETURN` / `LEAVE` 后退时，高于后退下限每厘米允许的后退速度百分比。 |
| `GOAL_HALF_CM` | `30.0f` | **球门背板/后墙切换半宽（cm）**：摄像头推算的横向位置 `|x| < 30cm` 时认为后方是球门（用 `12cm` 基准），否则为后墙（用 `18cm` 基准）。 |
| `US_BALL_SKIP_DEG` | `30.0f` | **球体遮挡过滤角**：当球距离很近且处于某超声波方向 `± 30°` 内时，忽略该超声波读数（防止把球误判为墙壁）。 |

## 7. 巡线传感器位掩码（Line Sensor Bitmasks）

| 参数名 | 定义值 | 中文含义与用途 |
| :--- | :--- | :--- |
| `M2(ch)` | `(1UL << (16 + (ch)))` | **第二路多路复用器（Mux 2）位偏移宏**：将 Mux 2 的通道号映射到 32 位 `lineState` 的高 16 位。 |
| `FRONT_IN` | `M2(7)` | **前内侧传感器**：位于 `FRONT_OUT` 后方的辅助前传感器；若它压线，说明机器人冲过头了，需微幅后退。 |
| `FRONT_OUT` | `M2(11)` | **前外侧停靠传感器**：位于中心前方 `8.0cm` 处，是本版代码（`smach3`）的核心停靠基准点，防守时需保持压在禁区线上。 |
| `BACK` | `(M2(4) \| M2(3))` | **后侧双传感器**：机器人尾部传感器，压线用于判断是否已完全冲出禁区或退到球门底线。 |
| `RING_FRONT` | `(1UL << 4)` | **圆环正前传感器**：Mux 1 圆环第 4 通道（`90°` 方向，半径 `6.1cm`），若它压线也说明机器人偏前，需后退。 |
| `FRONT_ANY` | `FRONT_IN \| FRONT_OUT \| RING_FRONT` | **任意前向传感器组合**：只要其中任一触发，即判定前端已接触到禁区线（用于 `RETURN -> DEFEND` 切换及屏蔽摄像头深度判断）。 |
